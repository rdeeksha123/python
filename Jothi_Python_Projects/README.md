# Python Mini and Major Projects

This repository contains two Python console projects.

## 1. Tic-Tac-Toe Game
Folder: `TicTacToe`

A two-player game with board display, input validation, win detection, draw detection, and replay.

## 2. Student Management System
Folder: `StudentManagementSystem`

A Python and SQLite project with user login, admin/staff roles, and student record management.

## Requirements
Python 3. No additional packages are required for these projects.

Open each project folder in PyCharm and follow the README inside that folder to run it.

These projects are for learning. Read and understand the code, test it, and make changes you can explain before submitting it.
